SEYD
Remote operation infrastructure
for autonomous vehicles and robots.
Seyd is a connectivity layer — an agent SDK on the robot, a pilot SDK in the browser, and a signaling cloud that brokers a direct, point-to-point connection between them over the public internet. Low-latency video, sensor data and commands. No transcoding. No relay. Your stack, your UI.
VideoH.264 · single encode chain · no jitter buffer · WebCodecs
TransportQUIC datagrams over WebTransport, peer to peer
ResilienceReed-Solomon FEC per block · recovery in one round trip
IntegrationRust core with a C ABI · seydd daemon · web components
