# ADR 0003 — Media over QUIC (MoQ): not adopted for v2

**Status:** accepted (2026-08-28); revisit at the relay-tier decision

## Context

MoQ (draft-ietf-moq-transport) is being productised by Cloudflare and others
and demonstrated interop at NAB 2026. SPEC.md asked whether Seyd should adopt
it as the video transport spec instead of its own chunk framing.

## Decision

Not for v2. MoQ's value is relay and CDN fan-out with a pub/sub object model —
exactly the tier the owner has deferred. Seyd v2 is point-to-point only, and
its framing (ADR 0001) is tuned for what P2P teleoperation needs: per-block
FEC, sub-frame pipelining, send timestamps, and a 20-byte header.

MoQ's object model (track / group / object) maps cleanly onto Seyd's
(channel / GOP / frame), and datagram delivery of objects is in-draft, so a MoQ
adapter can be added later without changing the SDK API.

## Trigger for revisiting

When the relay tier is designed, or if a customer needs interop with a MoQ
relay network. Track draft status quarterly.
